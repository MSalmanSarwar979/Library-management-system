# Library Management System

A Python-based Library Management System with a CustomTkinter desktop interface and custom data structures for efficient book and member management.

## Features

- Dashboard with library statistics
- Book management and search
- Member management
- Book borrowing and returns
- Transaction management
- Reports
- AVL tree for book catalog operations
- Hash tables for member and author lookup
- Dark-mode CustomTkinter GUI

## Data Structures

- **AVL Tree:** stores and searches the book catalog while maintaining a balanced tree.
- **Hash Table:** provides key-based lookup for members and author-to-book mappings.
